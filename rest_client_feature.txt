Цель: Rest client для выполнения и анализа http запросов к API и сайтам

Скриншоты с описание интерейса:

Экран разделен на области:
1) Слева Explorer 
    - выпадающий список проектов и кнопка для вызова контектного меню
        1. Создать проект - создает новый проект
        2. Переименовать проект - Вызывает редактор для указания имени проекта (появляется поле <input type="text"> для редактирования названия, 
           после нажатия Enter или потери фокуса происходит сохранение)
        3. Удалить проект - Удаляет проект
    - кнопка "Создать" - Создает новый запрос внутри проекта или без проекта (если он не выбран).
    - Кнопка "Импорт команды cURL из буфера обмена" - Получает из буфера обмена вызов команды cURL, 
      затем парсит (Понимает вызов bash Linux, windows) и создает запрос в текущем проекте или без проекта.
    - Список запросов с отображением HTTP метода + URL или название запроса если указано. 
      При выделении запроса появляется кнопка вызова контекстного меню (вызывается также по правому клику мыши). 
      При наведении на запрос меняется его фон.
    - контектное меню для запроса состоит из пунктов 
        1. Выполнить запрос - запускает текущий запрос на выполнение
        2. Копировать cURL - генерация команды cURL для bash Linux на основе указанных параметров запроса и отправка в буфер обмена. Уведомить пользователя об успешной отправке.
        3. Копировать cURL.exe - генерация команды cURL.exe для Windows на основе указанных параметров запроса и отправка в буфер обмена. Уведомить пользователя об успешной отправке.
        4. Переименовать - Вызывает редактор для указания имени запроса (При активации вместо HTTP метода + URL появляется поле <input type="text"> для редактирования названия)
        5. Дублировать - Создает копию текущего запроса
        6. Удалить - Удаляет запрос
2) Вертикальный разделитель для изменения ширины Explorer и правой области.
3) Правая область
    - сверху выпадающий список с Http method (GET, POST и т.д), поле для ввода URL, кнопка "Выполнить" с анимацией крутящегося глобуса.
      Нажатие кнопки во время выполнения прерывает запрос с показом уведомления "Запрос прерван".
    - область для параметров и ответа запроса
        1. Параметры
            - Вкладки (верхней области)
                1) Заголовки - Список Http заголовков (Name, Value). Используется компонент PropertyEditor из этого файла. Сделать autocomplete названий и значений.
                2) Запрос - Список параметров из Url (редактор параметров в Url запроса с мгновенной синхронизацией изменений). 
                   Используется компонент PropertyEditor из этого файла.
                3) Куки - Список Http cookies (Name, Value). Используется компонент PropertyEditor из этого файла. Мгновенная синхронизация изменений с заголовком Cookie (вкладка Заголовки).
            - горизонтальный разделитель для изменения высоты верхней области
            - Вкладки для тела запроса (Http request body в нижней области)
                1. Json - редактируемый компонент CodeMirror для json. В верхней панеле CodeMirror отобразить кнопку Форматирования Json в виде иконки.
                2. Xml - редактируемый компонент CodeMirror для xml. В верхней панеле CodeMirror отобразить кнопку Форматирования Xml в виде иконки.
                3. Text - редактируемый компонент CodeMirror для text
                4. Form-encode - таблица параметров для application/x-www-form-urlencoded. Используется компонент PropertyEditor из этого файла.
        2. Вертикальный разделитель для изменения ширины правой области
        3. Ответ запроса
            - Вкладки
                1) Ответ - ответа htpp запроса
                    - Сверху панель с информацией и кнопками
                        1. Label "Статус" - код Http status (200, 400 и т.д)
                        2. Label "Размер" - размер http response body (В формате bytes, Kib, Mib)
                        3. Label "Время" - время выполнения запроса (В формате ms, sec с дробной частью до двух знаков)
                        4. Checkbox "Сохранить" - указывает надо ли http response body сохранять в БД. Значение чекбокса тоже нужно сохранять в БД.
                           Отображается только для текстовых ответов (Html, Json, Xml, text и т.д.)
                        5. Кнопка "Форматировать" - отображать в виде икноки, когда тип ответа Xml/Json. Форматирует XML/Json с отступом 4.
                        6. Кнопка "Дэкранировать" - отображать в виде иконки, когда тип ответа Xml/Json. Деэкранирует XML/JSON.
                        7. Кнопка "Предпросмотр" - показывается только для ответов с типом Html. Активирует режим предпросмотра Html в <iframe sandbox>.
                        8. Кнопка "Копировать в буфер обмена" - копирует http response body в буфер обмена
                    - Под панелью отобразить Http Response Body в компоненте CodeMirror (нередактируемый) кроме ответов с бинарными данными.
                        Если в ответе файл (Content-Disposition: attachment), то отобразить просто кнопку для скачивания 
                        (При этом не загружать http response body до нажатия кнопки путем проверки http заголовка).
                        Если в ответе пришел Html и активирован режим Предпросмотра, то отобразить iframe для текущего Url.

                2) Заголовки - нередактируемый список заголовков http response (Таблица с названием и значением)
                3) Необработанный запрос - отображает Raw содержимое запроса, которые отправляется серверу. 
                   Также сверху содержит кнопки
                    - cURL (Posix) - генерация команды cURL для bash Linux на основе указанных параметров запроса и отправка в буфер обмена. Уведомить пользователя об успешной отправке.
                    - cURL (Windows) - генерация команды cURL.exe для Windows на основе указанных параметров запроса и отправка в буфер обмена. Уведомить пользователя об успешной отправке.



В БД Sqlite должны сохраняться:
    1) Проекты (Название)
    2) запросы со всеми параметрами 
        - Http Метод
        - Http Url
        - Название
        - Http Заголовки (отдельная таблица с полями Название и значение)
        - http request body (Clob)
        - тип http request body (enum json, xml, text, form-encode)
        - Чекбокс Save из панели с Ответом
        - Http response body (Clob) - только для текстовых ответов (Html, Json, Xml, text и т.д.)
        - Http Response headers
        - Необработанный запрос (Raw)

Общие компонеты:
1) PropertyEditor - Таблица редактирования списка с названием и значением, где первая строка для создания, остальные строки для редактирования. 
    При наведении на существующее свойство появляется В правой части и поверх поля ввода значения внопка удаления свойства.

Чтобы избежать ошибок CORS при выполнение запроса, возможно придется реализовать отправку запроса на стороне backend.
