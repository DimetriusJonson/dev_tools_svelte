Роль: Ты опытный [проджект-менеджер / архитектор / аналитик] в сфере Веб-разработки.

Контекст: Веб-приложение - инструменты для веб-разработчика.

Задача: Составь пошаговый план реализации задачи. 
Необходимо добавить страницу Wsdl-клиент. В панель навигации добавляется кнопка WSDL. Примерный UI в wsdl_ui.png.
Страница поделена на две области:
1) Explorer:
   - выпадающий список для выбора проекта (аналогично странице Rest client).
   - под ним кнопка для Импорта WSDL(URL wsdl файла) из буфера обмена (Парсинг WSDL файла).
   - Справка от кнопки импорта 
   - Под кнопками список WSDL файлов в виде дерева.
		Иерархия дерева:
			WSDL file - справа кнопка "..." для вызова контекстного меню с пунктами меню Выполнить, Удалить. Аналогично Rest client.
				WSDL service
					WSDL operation (При выборе отображается в правой области)
2) Вертикальный разделитель для изменения размера правой области.
3) Область справа от Explorer для текущей SOAP Operation
	- Выпадающий список <soap:address location>. Справа от него кнопка в виде глобуса для Выполнения запроса. Повторное нажатие отменяет запрос. Аналогично Rest client.
	- Область для запроса и ответа
		1) SOAP Input Вкладки:
			- XML: Компонент CodeMirror - Содержимое SOAP input body (после импорта Wsdl файла нужно сгенерировать шаблон) на основе схемы из Wsdl файла для текущей операции
			- Headers: Редактируемая таблица HTTP заголовков (PropertyEditor компонент) (При создании нужно сгенерировать согласно спецификации SOAP). Причем обязательные (если указано в стандарте SOAP) заголовки редактировать и удалять нельзя.
			- Raw: Сгенерированный SOAP запрос (SOAP envilope)
		2) Вертикальный разделитель для изменения размера правой области.
		3) SOAP Output Вкладки:
			- XML: Компонент CodeMirror - Содержимое SOAP output body (из ответ сервера)
				   Над компонентом панель с информацией (Status, Time, Size), checkbox (Save) и кнопками: "Copy to Clipboard", "Format". Аналогично rest client
			- Headers: Нередактируемая таблица HTTP заголовков из ответа сервера
			- Raw: Компонент CodeMirror (нередактируемый) - Полный Response body из ответа сервера. 
				   Над компонентом панель с кнопками: "Copy to Clipboard", "Format". Аналогично вкладке XM
					   
Необходимо проекты и сервисы с операциями хранить/читать в БД Sqlite.					   
				
	
Ограничения: По возможности для реализации использовать тот же набор библиотек и фреймворков.
Формат ответа: Таблица или нумерованный список с колонками: Шаг, Действие, Результат/критерий готовности, Оценка времени, Риски.
Сначала задай до 5 уточняющих вопросов, если не хватает критических данных, затем предложи базовый план.
