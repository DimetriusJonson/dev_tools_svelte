Цель: Добавить возможность на страницах Rest Client и Wsdl ииспользовать глобальные переменные вместо значений запросов(Query params), заголовков(Request Headers) и 
использовать их в теле запроса (Request Body). 
Переменные делятся на два типа:
1) Обычные - хранятся в БД (Тип, имя и значение).
2) Безопасные - Тип и имя хранятся в БД, а значение хранится в безопасном хранилище (tauri-plugin-keyring)

UI

Добавить отдельную страницу для редактирования и просмотра глобальных переменных. 
Добавить в панель навигации кнопку "Global vars" в виде иконки (Слева от кнопки "Проверить обновление").
Тип переменной указывается с помощью иконки с замочком (Замочек активен - безопасная, иначе - обычная).
Не допускать создать несколько переменных с одинаковым названием.
Добавить кнопку для копирования названия переменной в буфер обмена в виде шаблона "{{ var_name }}".
На стороне Backend заменять шаблон {{ var_name }} на реальное значение.
Для безопасных переменных значение скрыть звездочками, раскрывать путем нажатия кнопки с иконкой глаза.
